Laboratorio de Ejercicios Matemáticos

1. Ecuación Cuadrática

Calcula las raíces de ax² + bx + c = 0 mediante D = b² - 4ac.

2. Estimación de Pi

Calcula Pi mediante la serie: sqrt(6 * sumatoria(1 / n²)).

3. El Reparto de los Camellos

Descripción: Beremiz ayuda a repartir 35 camellos entre 3 hermanos agregando 1 camello prestado.

4. El Pago de los Panes

Descripción: Dos viajeros comparten sus panes con un tercero, quien paga 8 monedas de oro.
